O robô obediente

O computador obedece, mas não pensa sozinho. “Faz um sanduíche” trava o robô.

Você precisa dizer: pegue o pão → abra o pão → passe manteiga → coloque o queijo → feche o pão.

Lógica é dar ordens tão claras que até o robô entende.

Python do Zero ao Especialista14
Aula 1 · explicação técnica

Três estruturas fazem todo algoritmo

Sequência

Instruções executadas uma após a outra.

Decisão

Escolher um caminho por uma condição: if / elif / else.

Repetição

Repetir um bloco: for (vezes conhecidas) e while (até mudar).

Método profissional: entender → entrada e saída → pseudocódigo → teste à mão → código.

Python do Zero ao Especialista15
Aula 1 · exemplo real

Aprovado ou reprovado?

# Entrada: duas notas | Saída: mensagem
nota1 = float(input("Nota 1: "))   # sequência
nota2 = float(input("Nota 2: "))
media = (nota1 + nota2) / 2

if media >= 7:                       # decisão
    print(f"Aprovado com média {media:.1f}")
else:
    print(f"Reprovado com média {media:.1f}")

Erro clássico: usar > no lugar de >= e reprovar quem tirou 7,0.

LÓGICA DE PROGRAMAÇÃO
 ├─→ Problema → Entrada → Processamento → Saída
 ├─→ Sequência → um passo após o outro
 ├─→ Decisão → if / elif / else → Verdadeiro ou Falso
 ├─→ Repetição → for (quantidade conhecida)
